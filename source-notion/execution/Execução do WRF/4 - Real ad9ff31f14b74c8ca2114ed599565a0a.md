Esse passo a passo também pode servir como teste de instalação do modelo. Para isso, o modelo foi executado tanto em modo serial como em paralelo com diferentes números de processadores. Dessa forma, as páginas 4 e 5 devem ser feitas para todos os casos e os arquivos devem ser colocados em diferentes diretórios.

1 - Gere um link do executável do real no diretório desejado, dependendo de como será feita a rodada (serial, dmpar ou smpar):

```bash
ln -s ~/WRF/Build_WRF/serial/WRF/run/real.exe real.exe
```

```bash
ln -s ~/WRF/Build_WRF/dmpar/WRF/run/real.exe real.exe
```

```bash
ln -s ~/WRF/Build_WRF/smpar/WRF/run/real.exe real.exe
```

2 - Gere um link dos arquivos gerados pelo metgrid para o diretório desejado. $MET_PATH é o caminho onde esses arquivos estão.

```bash
ln -sf $MET_PATH/met_em* .
```

O namelist.input é um arquivo de configuração de rodada.

Ele deve refletir as mesmas informações do namelist.wps utilizado pelo geogrid.

Quando o WRF é compilado, ele gera um namelist.input padrão.

A ideia é alterar esse namelist original para manter o padrão que o WRF já entende.

1. Copie esse namelist original para ter um namelist que não seja alterado. **Esse passo só deve ser executado 1x.**

```bash
cp ~/WRF/Build_WRF/serial/WRF/run/namelist.input ~/WRF/Build_WRF/serial/WRF/run/ORI_namelist.input
```

A ideia é sempre copiar o namelist (namelist.input) para a sua pasta de interesse a alterar de lá. E caso ocorra algum erro nesse processo (caso esqueça de fazer essa cópia), o ORI_namelist.input estará intacto.

1. Copie o namelist.input para o seu diretório de interesse e modifique-o conforme namelist.wps.

```bash
cp ~/WRF/Build_WRF/serial/WRF/run/namelist.input .
```

1. Rode o real.

```bash
./real.exe
```

```bash
mpirun -np 2 ./real.exe
```

1. Verifique o final dos arquivos "rsl" ou o final do seu terminal para ter certeza de que a execução foi finalizada com sucesso.

```bash
tail rsl.error.0000
```

1. Se verificar um "SUCCESS", além dos arquivos “wrfbdy_d01”, e “wrfinput_d0*” para cada domínio, a rodada foi finalizada com sucesso.
